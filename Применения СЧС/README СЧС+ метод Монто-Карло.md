# sns-MC: Структурная Числовая Симметрия + Монте-Карло

Полная стабильная версия скрипта для вычисления числа π методом Монте-Карло с использованием гипотезы Структурной Числовой Симметрии (СЧС). Скрипт не только производит вычисления, но и генерирует наглядную анимацию процесса, а также экспортирует подробную статистику.

**Совместимость:** Julia 1.10 – 1.11  
**Автор:** Ющенко Михаил Юрьевич  

## 📖 Описание алгоритма
Классический метод Монте-Карло для вычисления π использует случайные точки в квадрате и проверяет, попали ли они в четверть круга. Данный скрипт модифицирует подход, добавляя фильтр на основе СЧС:
1. Координаты точки масштабируются и объединяются в одно большое целое число `N`.
2. К числу применяется оператор СЧС (разбиение на `m` частей и умножение на `k`).
3. Результат сравнивается с контрольным значением `N * k`.
4. В расчет π методом СЧС учитываются только те точки, которые прошли проверку на структурную симметрию.

  ```bash

  ```

## ⚙️ Настройка параметров

В блоке `# ---------- ОСНОВНОЙ ЗАПУСК ----------` можно изменить следующие переменные:

- `N_SAMPLES` — общее количество итераций (по умолчанию `10000`).
- `M_PARAM` — параметр `m` для СЧС (на сколько частей разбивать число).
- `K_PARAM` — параметр `k` (множитель для частей числа).

## 📁 Генерируемые файлы

После успешного выполнения в рабочей директории появятся:

- **`sns_mc_raw_data.csv`** — сырые данные по каждой итерации (координаты, попадания, текущие значения π).
- **`sns_mc_summary.csv`** — итоговая сводная статистика (ошибки, средние значения, распределение типов симметрии).
- **`sns_mc_animation.mp4`** — визуальная анимация процесса попадания точек в четверть круга с цветовым кодированием валидности СЧС.
