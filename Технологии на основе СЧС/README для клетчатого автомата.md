**Structural Numerical Symmetry Cellular Automaton (SNS-CA)** — тип динамической системы, основанный на внутренних арифметических свойствах чисел, а не на пространственном взаимодействии соседних клеток.

> ⚠️ **Юридическое уведомление:** Данная работа защищена усиленной электронной подписью (УЭЦП). Все права на интеллектуальную собственность принадлежат автору. Копирование, распространение и использование материалов без указания авторства запрещено и преследуется по закону.

## 🚀 Смена парадигмы

Традиционные клеточные автоматы (такие как Game of Life или Rule 30) жестко привязаны к пространственному взаимодействию: состояние клетки диктуется её соседями (правило фон Неймана-Улама). 

SNS-CA отходит от данного правила. В предлагаемой системе клетки не взаимодействуют друг с другом. Эволюция определяется внутренней арифметической симметрией самого числа. 

Это формирует новое направление — **Арифметические клеточные автоматы (Arithmetic Cellular Automata)**, где пространственное взаимодействие заменяется структурой числа. Клетка не взаимодействует с соседями; эволюция определяется внутренней структурой. Отказ от классического правила соседства определяет SNS-CA как уникальный тип динамической системы.

## 📖 Принцип работы

Эволюция каждой клетки определяется внутренними свойствами её числового состояния через три шага:

1. **Разбиение** числа N на m частей
2. **Умножение** каждой части на k
3. **Сравнение** результата с N·k по префиксам и суффиксам

В зависимости от результата, клетка переходит в одно из пяти состояний:
- **F (Full)** — полное совпадение
- **B (Boundary)** — совпадение начала и конца
- **E (End)** — совпадение только конца
- **S (Start)** — совпадение только начала
- **N (No)** — нет совпадений (клетка переходит в нулевое состояние)

## 📊 Параметры

| Параметр | Описание | Значение по умолчанию |
|----------|----------|-----------------------|
| `L` | Размер сетки (L×L) | 75 |
| `steps` | Количество итераций | 300 |
| `m` | Количество частей для разбиения | 2 |
| `k` | Множитель | 3 |
| `min_val` | Минимальное начальное значение | 10⁴ |
| `max_val` | Максимальное начальное значение | 10⁸ |

##  Визуализация

Цветовая схема состояний:
- ⚫ **Чёрный** — нулевое состояние (N)
-  **Золотой** — полное совпадение (F)
- 🟢 **Зелёный** — граничное совпадение (B)
- 🔴 **Красный** — совпадение конца (E)
- 🔵 **Синий** — совпадение начала (S)
